# mbt-sandbox

A throwaway project for testing mbt 3's release pipeline (`mbt release`,
`mbt prerelease`, and the reusable workflows `build3.yml` and `release3.yml`
of mvslovers/mbt). Nothing here is meant to be used.

**Never receive its SMP package on any system.** `TSBX` is a test id; the
package exists only to exercise the packaging step.
